= Installation

== As a Library

Add to your `shard.yml`:

[source,yaml]
----
dependencies:
  crystal-asciidoctor-diagram:
    github: aloli-crystal/crystal-asciidoctor-diagram
    version: "~> 3.2"
----

Then run `shards install`.

== CLI Binary

[source,bash]
----
git clone https://github.com/aloli-crystal/crystal-asciidoctor-diagram.git
cd crystal-asciidoctor-diagram
shards build --release
----
