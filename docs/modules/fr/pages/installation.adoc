= Installation

== En tant que Bibliotheque

Ajoutez a votre `shard.yml` :

[source,yaml]
----
dependencies:
  asciicrystal-diagram:
    github: aloli-crystal/asciicrystal-diagram
    version: "~> 3.2.1.3"
----

Puis executez `shards install`.

== Binaire CLI

[source,bash]
----
git clone https://github.com/aloli-crystal/asciicrystal-diagram.git
cd asciicrystal-diagram
shards build --release
----
